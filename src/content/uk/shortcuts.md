# Комбінації клавіш

Короткий довідник з комбінацій клавіш Syto. Комбінації активні, коли діалогове вікно не відкрите і ви не вводите текст у поле вводу.

## Навігація

| Комбінація   | Дія                           |
| ------------ | ----------------------------- |
| `Arrow Up`   | Перейти до попереднього кроку |
| `Arrow Down` | Перейти до наступного кроку   |

## Дії

| Комбінація                     | Дія                                     |
| ------------------------------ | --------------------------------------- |
| `Ctrl+Z` / `Cmd+Z`             | Скасувати останню операцію з пайплайном |
| `Ctrl+Shift+Z` / `Cmd+Shift+Z` | Повторити скасовану операцію            |
| `Ctrl+S` / `Cmd+S`             | Завантажити робочий процес як JSON      |
| `Delete`                       | Видалити крок, який ви переглядаєте     |
| `Escape`                       | Закрити діалог або скасувати виділення  |

## Імпорт даних

| Комбінація         | Дія                                          |
| ------------------ | -------------------------------------------- |
| `Ctrl+V` / `Cmd+V` | Вставити табличні дані з буфера обміну       |
| Drag & Drop        | Перетягніть CSV-файли в програму для імпорту |

## Таблиця даних

| Комбінація               | Дія                                     |
| ------------------------ | --------------------------------------- |
| `Arrow Left/Right`       | Навігація між заголовками стовпців      |
| `Shift+Arrow Left/Right` | Розширення виділення діапазону стовпців |
| `Arrow Up/Down`          | Навігація між рядками                   |
| `Shift+Arrow Up/Down`    | Розширення виділення діапазону рядків   |
| `Enter` / `Space`        | Вибрати заголовок стовпця або рядок     |

## У діалогових вікнах

| Комбінація          | Дія                          |
| ------------------- | ---------------------------- |
| `Tab` / `Shift+Tab` | Переміщення між полями форми |
| `Enter`             | Застосувати поточний діалог  |
| `Escape`            | Скасувати та закрити діалог  |
